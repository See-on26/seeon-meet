SEEON Windows 설치 안내
버전 {{VERSION}} · 빌드 커밋 {{COMMIT}} ({{REF}}) · 만든 때 {{BUILT_AT}}

1. 설치
  - SEEON-Setup-{{VERSION}}.exe 를 더블클릭합니다.
  - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다. 서명하지 않은 앱이라 처음에 한 번 뜹니다.
  - 관리자 권한 없이 설치되고, 바탕화면과 시작 메뉴에 SEEON 아이콘이 생깁니다. 설치가 끝나면 앱이 바로 켜집니다.
  - 다음부터는 바탕화면의 SEEON 아이콘을 더블클릭해서 켭니다.
  - 새 버전을 받으면 그 설치 파일을 그대로 실행하면 됩니다(지우지 않고 덮어 설치).

2. 처음 켰을 때
  - 왼쪽 창에서 Google Meet 에 로그인하고 회의에 들어갑니다.
  - 오른쪽 위 SEE-ON 로고를 빠르게 5번 눌러 개발자 모드를 연 뒤, 톱니(설정) 맨 아래 개발자 진단에서 "GPU 서버: 연결됨" 인지 봅니다.
    "다시 연결 중" 이 계속되면 회사·학교 방화벽이 GPU 서버 접속 포트를 막은 것일 수 있으니 다른 네트워크(휴대폰 핫스팟 등)로 바꿔 봅니다.
  - 영어 회의라면 설정에서 회의 언어를 English 또는 자동(한·영)으로 고른 뒤 캡처를 시작합니다.
  - 오른쪽의 [회의 캡처 시작] 을 누르면 화면 해설이 시작됩니다.

3. 확인해 주세요(Windows 에서 처음 돌려 보는 것이라 결과를 알려 주세요)
  [ ] 설치되고 바탕화면에 SEEON 아이콘이 생김
  [ ] 아이콘 더블클릭으로 켜짐
  [ ] Meet 로그인, 카메라·마이크 권한
  [ ] 회의 캡처 시작 → LIVE 로 바뀜
  [ ] 설정의 "GPU 서버: 연결됨"
  [ ] 화면 해설 소리가 나옴
  [ ] 질문(Ctrl+M 마이크, Ctrl+1~9 질문 프리셋 또는 입력창)에 답이 나옴
  [ ] 회의 요약(Ctrl+0)
  [ ] 문서\SEEON 회의 기록 폴더에 회의 기록이 쌓임

4. 문제가 생기면
  - 증상, 시각, 화면 사진과 함께 아래 폴더의 pipeline-*.jsonl 파일을 보내 주세요.
    탐색기 주소창에 %APPDATA%\SEEON\out 을 입력하면 열립니다.

5. 지우기
  - 설정 → 앱 → 설치된 앱 → SEEON → 제거

6. 보안
  - 이 설치 파일 안에는 팀 GPU 서버 접속 키가 들어 있습니다.
    다른 사람에게 전달하거나 인터넷·메신저 단체방에 올리지 마세요.
  - 예전 테스트 키트(tunnel.sh, 관리자 키 파일)는 이제 필요 없습니다. 앱이 GPU 서버에 직접 연결합니다.
