SEEON Lab(실험 창) Windows 설치 안내
버전 {{VERSION}} · 빌드 커밋 {{COMMIT}} ({{REF}}) · 만든 때 {{BUILT_AT}}

녹화한 회의·발표 영상을 SEEON 화면에 회의 대신 넣어 돌리고, 들린 해설·전사·파이프라인 흐름을 결과 폴더로 남기는
평가·시연용 앱입니다. 제품 SEEON 과 따로 설치되므로 둘 다 깔아 두고 써도 됩니다.

1. 설치
  - SEEON-Lab-Setup-{{VERSION}}.exe 를 더블클릭합니다.
  - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다. 서명하지 않은 앱이라 처음에 한 번 뜹니다.
  - 관리자 권한 없이 설치되고, 바탕화면과 시작 메뉴에 SEEON Lab 아이콘이 생깁니다. 설치가 끝나면 앱이 바로 켜집니다.
  - 새 버전을 받으면 그 설치 파일을 그대로 실행하면 됩니다(지우지 않고 덮어 설치).

2. 쓰는 순서
  - 왼쪽 위가 조작 바, 왼쪽 아래가 재생 화면, 오른쪽이 SEEON 화면입니다.
  - [영상 선택] 으로 녹화 영상(mp4 등)을 고르면 재생 화면에 영상의 첫 화면이 뜹니다.
  - 녹화에 발표자 얼굴 타일 등이 섞여 있으면 [ROI 편집] 을 누르고 공유 화면 영역을 드래그해 맞춥니다.
  - 모드(기본 균형), 회의 언어(한국어 · English · 자동(한·영)), 평가 설정(기본 켜짐)을 고르고 [시작] 을 누릅니다.
    영어 영상은 회의 언어를 English 또는 자동(한·영)으로 고릅니다.
  - 영상이 끝나면 남은 해설을 기다렸다가 저절로 마무리합니다. 중간에 끝내려면 [정지] 를 누릅니다.
  - [결과 폴더] 로 이번 실행의 결과를 엽니다. [시연 창] 은 들린 해설을 큰 글씨 카드로, [파이프라인] 은 단계별 흐름을 보여 줍니다.

3. 결과 폴더
  - 탐색기 주소창에 %APPDATA%\seeon-lab\out\lab 을 입력하면 실행마다 "<날짜-시각>-<영상 이름>" 폴더가 있습니다.
  - run.json(실행 설정), ad-timeline.json · ad.srt(들린 해설과 시각), output-audio.webm(SEEON 이 낸 소리),
    transcript.txt(전사), flow.json(흐름), pipeline.jsonl(파이프라인 기록)이 들어 있습니다.

4. 확인해 주세요(Windows 에서 처음 돌려 보는 것이라 결과를 알려 주세요)
  [ ] 설치되고 바탕화면에 SEEON Lab 아이콘이 생김
  [ ] [영상 선택] 뒤 재생 화면에 첫 화면이 뜸
  [ ] [ROI 편집] 으로 영역을 맞출 수 있음
  [ ] [시작] 뒤 SEEON 화면이 LIVE 로 바뀌고 해설 소리가 나옴
  [ ] SEEON 화면 오른쪽 위 톱니(설정)의 "GPU 서버: 연결됨"
  [ ] 끝난 뒤 결과 폴더에 output-audio.webm · ad.srt · transcript.txt 가 생김

5. 문제가 생기면
  - 증상, 시각, 화면 사진과 함께 그 실행의 결과 폴더를 통째로 보내 주세요.
    결과 폴더가 없으면 %APPDATA%\seeon-lab\out 의 pipeline-*.jsonl 파일을 보내 주세요.

6. 지우기
  - 설정 → 앱 → 설치된 앱 → SEEON Lab → 제거

7. 보안
  - 이 설치 파일 안에는 팀 GPU 서버 접속 키와 AI 서비스(Bedrock) 토큰이 들어 있습니다.
    다른 사람에게 전달하거나 인터넷·메신저 단체방에 올리지 마세요.
